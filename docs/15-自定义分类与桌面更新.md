# HawTend：自定义分类与桌面更新

日期：2026-10-06。用户要求将记录日子时的固定分类改为自己设置。已完成本地原型与 Windows **0.0.6.0** 更新。

## 使用方式

记录日子或编辑心愿时，点击分类下拉框旁的 **管理分类**；也可以打开 **手账设置**。

- 新增分类，填写自己的名称，例如工作、家人、兴趣。保存后会自动选中新增分类。
- 编辑名称、颜色和小图案；提供八种手账配色及自由颜色选择、八种图案。
- 分类名称最多 20 个字符，不接受空白或重复名称；最多保留 32 个分类。
- 删除未使用的分类，至少保留一个。已有记录或心愿使用中的分类不能直接删除，先调整这些记录的分类后即可删除。
- 名称和配色调整立即反映到记录标签、心愿卡片与时间轴筛选。分类 ID 保持不变，原记录仍属于同一分类。
- 修改分类可以通过保存提示撤销。分类保存独立于正在填写的记录，标题和感想不会被提交或清空，记录仍需单独点击“收进手账”。

分类设置与个人手账一起保存到当前浏览器，刷新和离线重开仍保留。JSON 导出包含分类定义。样例中的设置只存在于本次体验，不写入个人手账。当前尚无登录与云同步。

## 数据兼容

手账 `schemaVersion` 维持 1，增加可选的 `categories` 定义数组。旧手账没有此字段时，读取阶段在内存中补齐生活 / 成长 / 远行 / 健康定义，不自动写入数据库。首次明确保存分类或记录时写入个人键；旧 `current` 键保留。

旧记录的 ID、事件经过、感想、金额和分类 ID 不修改。仅分类设置被改过的旧样例也会被识别为个人修改，继续保留。分类元数据无效或记录引用不存在分类时暂停加载 / 拒绝保存，保留原存储内容。同步前的数据格式校验也支持可选分类定义，拒绝重复 ID、非法颜色和无归属记录；本次未修改数据库迁移或调用云端服务。
