# 区间支出估算与期初补录

2026-11-17 · v0.0.24

一次余额核对只回答“这一天有多少钱”。即使所有账户都更新了，如果没有期初余额，或不知道这段时间实际到账的收入，就不能从期末反推出支出。旧流程把估算放在账户列表之后，也没有给已核对完的用户一个直接的下一步。

1. 点「资金安排」，默认进入「账户记账」，顶部显示最近一次余额核对的支出状态。可在账户区改日期或点“切到今天”。已保存的账户快照继续使用。
2. 缺期末时列出账户名称。如果资产明细已有该日的完整记录，可以带入对应账户快照。只使用同一天的明确金额，不用混合日期或预计余额，且不会覆盖已核对账户。
3. 期末齐全但缺期初时，点“补录期初余额”，选择上次核对日期，填各账户当天金额。可明确带入同一天的资产记录。只写期初快照，不动现在的资产、期末余额、历史月结。没有历史凭据时，本次保留为下次比较的基准。
4. 填入从期初到期末期间的实际到账收入。系统立即显示支出估算，不把空白收入当 0。日期匹配的基金盈亏自动带入；其他盈亏、利息和两端欠款默认按 0，实际有发生时展开调整。预计年化不会用来替代实际收益。
5. 点“怎么算出来的？”可查看代入的金额，再保存估算。以前确认的区间和旧月结都保留。区间估算不是逐笔消费明细。投资曲线仍能在资产页的“查看投资市值历史”展开，默认收起。

公式：**总支出估算＝期初净资产＋到账收入＋投资净收益−期末净资产**，净资产＝各账户余额合计−欠款。区间必须覆盖同一范围内的各笔钱。内部互转、赎回本金和借款到账不计为收入，买入基金不是消费；基金涨跌和实际利息各只计一次。

虚构样例：期初账户 100,000 元、期末 106,200 元，到账收入 10,000 元，投资盈利 200 元。如果两端无欠款，支出估算 4,000 元；若期末新增 100 元欠款，支出估算 4,100 元。
