# HawTend：G 品牌统一与桌面更新

日期：2026-10-05。用户确认“用方案 G，统一成这个”。默认应用现使用 **G 细线手绘山楂 + Lora 字体**。

## 统一范围

- 桌面侧栏与手机页头：保留已审阅的叶片、淡色果实与细线轮廓，字标使用本地 Lora、字重 450。
- 浏览器 favicon、Apple 主屏幕图标、PWA 常规与可裁切图标：由同一份 SVG 生成，背景采用暖纸色。
- Windows 0.0.3.0：内置新版页面、离线字体与图标；EXE 与托盘共享 G 图标资源，ICO 包含 16、32、48、256px 四个尺寸。
- 默认网址与所有历史 `?brand=` 链接统一显示 G，候选切换代码已移除。历史图案和静态对照图继续保留。

当前入口：[本机应用](http://127.0.0.1:4173/)、[Windows EXE](../releases/windows/HawTend.exe)。手机需后续 HTTPS 托管才能安装，当前手机截图是 Chromium 视口预览。

个人记录、旧数据库与存储键未修改。个人手账继续从空白开始；“看看样例”继续使用独立的虚构内容。此次没有接入登录、云同步或部署云项目。

## 资产与维护

| 文件 | 作用 |
| --- | --- |
| [canonical SVG](../src/assets/hawtend-mark.svg) | 应用实际使用的矢量标记，与审阅时 G 的图形完全相同 |
| [公开 SVG](../public/brand/hawtend-logo.svg) | 同源分发的矢量副本 |
| [1024px 透明母版](../public/brand/hawtend-logo-source-1024.png) | 浏览器栅格化 SVG 得到，供图标缩放 |
| [256px 透明 Logo](../public/brand/hawtend-logo-256.png) | 常规图案导出 |
| [字标样式](../src/brand.css) | 自托管 Lora 和统一字体参数 |
| [字体许可](../public/brand/font-licenses/Lora-OFL.txt) | 保留原字体许可；运行时无需外部字体请求 |

`scripts/build-brand-icons.ps1` 通过 Playwright 将 SVG 渲染为透明母版，再用系统图像库生成各尺寸。没有重新绘制用户选定的图案。可裁切图标以 68% 画布尺寸绘制，图案位于中央 80% 直径的安全圆内，背景完全不透明。

HTML 和清单中的图标地址增加 `?v=g1`，静态资源离线匹配忽略查询参数，已检查这些地址在断网时仍可加载。已安装的主屏幕图标和 Windows 图标是否即时刷新仍由系统缓存决定，本次没有验证 iPhone 实际安装。

维护时由助手运行，Playwright CLI 需位于当前终端 PATH：

```powershell
$env:PATH = 'C:\Users\19620\.codex\tools\life-app-toolchain\node_modules\.bin;' + $env:PATH
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-brand-icons.ps1
npm run build
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -SkipWebBuild
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/inspect-windows-package.ps1
```
