# HawTend：品牌候选与整页效果

日期：2026-10-05。状态：候选已完成，等待选择后统一应用。

## 本轮要求

首版角色与手账页面的风格不够融合，原 Georgia 字标显得厚重。本轮以简约、融洽为首要要求，重新设计图标与 HawTend 字标；可以采用山楂、手账及 Hao / Wen 的名字元素，不限定可爱风。需要把多个方案放进实际页面比较。

保留暖纸色、鼠尾草绿与页面的线条图标，以低饱和山楂红作点缀。四套图标均直接绘制为原创 SVG，放大缩小保持清晰；字标由本地字体排版，与图标分开。

## 预览与数据规则

候选由 `?brand=a` 至 `?brand=d` 选择；只接受这四个值，不写入保存设置，也不修改个人记录。页面本身仍从空白个人手账开始，可点“看看样例”观察内容充实后的搭配。样例继续只在内存中运行。

无 `brand` 参数时仍使用首版品牌。此轮没有替换 PWA 安装图标或重新打包 EXE；待选定后再统一桌面、手机、安装图标和桌面包。现有 EXE 若自行启动旧的内置页面，不包含本轮预览入口；候选请使用上述运行中的本机链接或静态效果图。

## 字体与维护

使用 Manrope、DM Sans 与 Lora 的原始 Latin WOFF2 子集，原文件未经修改。对应 SIL Open Font License 1.1 和版权说明放在 `public/brand/font-licenses/`，构建产物与对照 HTML 也携带许可。官方来源见 [字体来源与许可](../public/brand/font-licenses/README.md)：[Manrope](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt)、[DM Sans](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt)、[Lora](https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt)。

页面运行时不请求 Google Fonts，字体随应用构建并缓存。候选 SVG 位于 `src/assets/brand-proposals/`，预览选择在 `src/brand-proposals.ts`，排版在 `src/brand-proposals.css`。

在已生成实际页面截图后，运行 `node scripts/build-brand-review.mjs` 可重新生成两个独立 HTML 对照文档；对应 PNG 由 Playwright 打开 HTML 后截取 `#comparison` 得到。脚本需要 `output/playwright/hawtend-brand-{a,b,c,d}-desktop-frame.png` 和 `-mobile.png`，这些截图应通过运行界面重新获取。
