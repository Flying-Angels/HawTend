## 怎样打开

1. 在项目根目录双击 **启动HawTend.cmd**，会自动打开浏览器。
2. 也可以直接访问 **http://127.0.0.1:4173/**。如果地址不可访问，使用上述启动入口。
3. 电脑重启后，重新双击启动入口。预览不会作为系统开机服务安装。

先前的 HTML 是基于 React/Vite 的项目入口，需要由本机 HTTP 预览加载脚本。通过 `file://` 双击源码或构建入口，无法加载完整 App；本次已给这两个入口补上可读的打开指引。

启动入口固定使用 4173 端口，复用已经正常运行的 HawTend，不会停止已有预览。若端口被其他程序占用，提示处理，不会悄悄改成另一个端口。这样可以保留同一个浏览器来源下已有的手账；仍应使用同一个浏览器和配置文件。没有清理或改名 IndexedDB。

启动脚本会查找现有 Node.js 与项目依赖，必要时重新构建页面，并在后台启动预览。不要求你租用服务器或维护数据库；未来的在线版仍按免费托管方案推进。构建、预览日志与本次启动 PID 位于 `output/preview/`，不会进入 GitHub。
