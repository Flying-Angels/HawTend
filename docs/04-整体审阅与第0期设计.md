## 2. 视觉提案

品牌定稿见 [G 品牌统一与桌面更新](14-G品牌统一与桌面更新.md)：用户选定 G 细线手绘山楂，沿用 Lora 字体，已统一应用。下面的首版 Q 版山楂描述保留设计过程；当前标记使用项目原生 SVG。

默认采用**暖纸手账**：纸张底色、鼠尾草绿、书页感中文标题、清晰正文和金额。山川插画和功能图标由代码原创绘制；品牌山楂由内置图像工具生成并保存到项目中，没有引入远程字体。

「手账设置」提供三套即时配色，保留同一布局与操作流程，便于比较氛围：

| 方向 | 背景 / 主色 | 气质 |
| --- | --- | --- |
| 暖纸手账，默认 | `#f5f2eb` / `#566958` | 安静温暖，接近日常手账 |
| 森林笔记 | `#edf1e9` / `#41654f` | 浅雾绿与深林色，清新自然 |
| 暮色日记 | `#f4eef0` / `#805d70` | 燕麦色与梅子色，柔软内敛 |

分类色独立于主题：生活为暖棕，成长为灰蓝，远行为青绿，健康为灰紫。原型暂有固定四类；正式版再开放自定义分类与颜色。

设计变量集中在 `src/styles.css`：本机宋体类标题、系统无衬线正文、衬线数字；4/8 像素间距节奏；主要圆角 7/11/14 像素。动画短且克制，响应减少动态效果偏好；手机编辑输入保持至少 16 像素字号。

## 4. 建议审阅流程

1. 在电脑打开 [本地原型](http://127.0.0.1:4173/)，看氛围、阅读舒适度和导航。
2. 在「手账设置」比较三套配色，可以随时切回暖纸手账。
3. 点击「搬进自己的小窝」，读事情与感想，补写几句话并保存，刷新后查看。
4. 打开「去看一次极光」，改日期、预算、已分配资金，观察月储蓄。改日期先预览，再确认，保存后可撤销。
5. 在「资金安排」查看 20 万元活期 1% 与 5 万元十年定期 5%，切换单利/复利，保存后查看目标试算。
6. 缩小窗口到手机宽度，体验底部导航、记录入口和详情面板。此操作不能代替 iPhone 实机检查。

请先使用虚构内容。真实资料等同步、导入恢复与数据保护完成后再录入。

## 5. 原型计算边界

参考日固定为 2026-10-05，金额按整数分保存。固定非负年化可自由修改，暂限定 0%—30%。单利/复利分开；完整周年按整数年计，零头按实际天数/365估算。定期到期前锁定本息，到期后默认零收益。

目标详情是**单目标简化试算**：只分配当前活期池，不能将定期未来到期资金分配给目标。多笔活期用余额加权年化近似，不分别应用各笔付息与计息方式。正式版需逐笔配置目标分配、收益、付息和到期条件。原型不汇总多个目标的月储蓄压力。

当前月末至目标日可发生的月末投入次数作为月数；已有分配资金也按该月数整月增长近似。新增储蓄按月末投入，年化转月利率，最后每月所需金额向上取整到分。正式版还需按实际参考日至目标日的时长细化。

示例：预算 100,000 元，已分配 30,000 元，1% 年化，27 次月末投入，月储蓄 2,539.86 元。加上临时试算开支 8,000 元与义务 2,000 元，月可支配收入 12,539.86 元。日期改成 2027-12-31 时月储蓄为 4,614.75 元。开支/义务暂只保留在详情内，未存入账单。收入指税后可支配收入。

目标分配总额不能超过活期余额，降低资金至已分配金额以下会阻止保存。手动进度独立于资金比例。50,000 元按 5% 十年单利为 75,000 元，按年复利为 81,444.73 元。收益是规划假设，未代表实际到账。

## 6. 状态与保存

| 状态 | 原型行为 |
| --- | --- |
| 加载 | 显示打开状态，读取完成前禁用新建 |
| 保存中 | 等待本地事务完成，再显示成功 |
| 本地保存 | 只说明此浏览器已保存，不宣称云同步 |
| 写入失败 | 保留详情和草稿，明确失败，可重试 |
| 读取失败 | 暂停写入、显示示例，防止覆盖未知内容 |
| 离线 | 缓存完成后可打开与编辑，显示离线本机保存 |
| 空范围/分类 | 显示空状态，引导切换或记录 |
| 云同步未连接 | 设置和页脚说明，可导出 JSON |
| 待同步/同步冲突 | 原型尚无真实同步；正式版设计待上传、失败重试与保留双方版本的冲突处理 |

导出包含目标、大事记、资金与配色。导入恢复、删除回收和完整历史未实现；撤销仅针对当前会话最近一次修改，提示保留约 10 秒。
