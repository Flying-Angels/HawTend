## 修复的实际问题

1. 正文和元数据过小：加大关键字号，手机编辑输入至少 16 像素。
2. 密集节点重叠：按缩放聚合，展开逐条查看；普通节点交替泳道排列。
3. 旧校验错误残留：每次提交清除旧错误，重新验证。
4. 清空目标日期可能造成月数循环不结束：改用常数时间计算，空/无效日期返回零，增加边界检查。
5. 预览服务的 `Vary: Origin` 使脚本/样式错过离线缓存：仅对同源静态资源使用 `ignoreVary`，保持认证/API 不缓存；新会话重新断网重载通过。参数行为见 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Cache/match)。
