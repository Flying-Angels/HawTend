# HawTend：独立 Windows 窗口与旧手账接续

版本：v0.0.12；核验日期：2026-10-06。

## 为什么之前使用 Edge

此前 EXE 是一个轻量启动器，用 Edge 的应用窗口显示与 iPhone PWA 共用的页面。这让原型可以免费快速运行，但窗口顶栏主要由浏览器决定，也使用浏览器自己的记录空间。

Windows 应用并不必须使用 Edge。现在改成 HawTend 自己的 C# / WinForms 窗口，内部使用免费的 WebView2 运行时显示现有页面。正常启动不再打开 Edge 浏览器窗口，顶栏、窗口按钮和退出由应用自己管理。WebView2 的运行时独立于 Edge 浏览器；这是微软提供的网页显示组件，仍然使用 Chromium 引擎。

Windows 与 iPhone 继续共用 React 页面和业务规则；iPhone 仍按 PWA 路线推进。没有加入收费开发工具，也不需要自行部署服务器。当前仍是本机原型，云同步尚未接入。

## 窗口与安装

- 顶栏延续纸色、透明山楂和简洁的窗口按钮；切换手账配色时一起更新。
- 可以拖动顶栏、双击最大化，使用最小化、最大化 / 还原、关闭按钮，并从边缘调整大小。
- 重复启动回到已有窗口；关闭窗口停止本机页面服务。托盘仍可打开或退出 HawTend。
- 支持 Windows 10 / 11 **x64**，需要 .NET Framework 4.8 和 WebView2 Evergreen Runtime。缺少运行时时，页面提供微软官方下载入口。运行时与应用开发方案免费，不需要安装 Edge 浏览器。
- 下载后完整解压，保留 EXE 同目录的 `Microsoft.Web.WebView2.Core.dll`、`Microsoft.Web.WebView2.WinForms.dll`、`WebView2Loader.dll`。仅复制 EXE 无法运行。

SDK 固定为 `1.0.4129.50`，构建脚本从微软 NuGet 下载并校验 SHA256；三份 DLL 与微软的再分发许可一起提供。运行时由微软维护更新，不把整个浏览器打进应用。

## 以前的记录如何接着使用

新窗口使用独立的本机记录空间：`%LOCALAPPDATA%\HawTend\WebView2`。正常升级或移动 EXE 仍读取这个位置，不随 EXE 版本更换。旧浏览器的记录不会自动移动，也不会被删除。

首次使用新窗口时，空白手账提供“接续旧手账”：

1. 点击“接续旧手账 → 打开旧手账”。这一步才会打开旧 Edge 页面。
2. 在旧页面点击“导出旧手账 JSON”，保存文件。
3. 回到新窗口，选择该 JSON，检查日子、心愿、资金和月度收支数量，再点击“确认接续这份手账”。

选择文件时不会直接写入记录。接续只对空白的个人手账开放；已有记录和样例手账不允许从此入口覆盖。文件结构、大小、分类、日期和资金数据会先校验，格式不符时拒绝写入。接续期间若当前手账发生变化，也会暂停；成功后刷新仍保留内容。

如果旧版使用其他浏览器或配置文件，请在**原来的浏览器**打开 `http://127.0.0.1:4173/`，通过手账设置导出，再到新窗口选择文件。打开旧页面后没有看到记录，不表示原记录被删除，先检查使用的浏览器和配置文件。

也可以“从空白开始”。只要仍没有个人记录，以后可从“手账设置 → 接续以前的手账”重新进入。原浏览器与新窗口不会互相同步，接续后建议在新窗口继续编辑。

导出 / 接续由使用者主动操作；不会读取浏览器配置文件中的账本文件、Cookie 或账号信息。接续不上传云端，源码仓库和安装包不包含个人记录。本机 HTTP 服务仍只提供内置静态资源，没有导入写入 API。

## 实际检查

- 在此 Windows 电脑的独立测试配置与端口验证真实 WebView2 页面、导入确认、重新加载保留、配色消息和标准 Windows 文件保存对话框。
- 通过实际窗口按钮验证最小化、最大化、还原、关闭；验证重复启动聚焦同一个窗口、边缘缩放命中和关闭后服务停止。
- 用虚构数据检查原浏览器导出后内容不变，日子与感想的 Markdown / LaTeX、资金金额和月结算完整保留。检查无效 JSON、错误结构、超大文件、未确认不写入、样例隔离和禁止覆盖已有记录。
- 手机浏览器视口仍正常，不显示桌面接续入口；没有进行 iPhone 真机安装测试。

## 更新提示

先导出旧手账并退出旧版本，再完整解压新版。第一次接续完成后，以后继续使用同一个 Windows 用户和记录文件夹即可。不要清理 `%LOCALAPPDATA%\HawTend\WebView2`，那是新桌面版的本机记录空间。

如果此前预览服务仍占用 `4173` 端口，先退出预览再打开桌面版。程序不会为了启动而自动换地址，也不会关闭普通浏览器窗口或终止共享的 Edge 进程。
