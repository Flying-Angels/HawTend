# v0.0.9 · 文字格式与实时日期

2026-10-06。两处正文改用一致的手账衬线字体，提供常用格式和数学公式；修复日期常量与时间轴圆点偏移。

## 使用方式

“发生了什么”“留给自己的话”均可选中文字后使用加粗、斜体、下划线工具，支持 Ctrl/⌘ + B、I、U，以及撤销/重做。工具栏提供行内和独立公式模板。编辑视图保留语法，预览视图展示排版。

行内公式使用 `$x^2$`，独立公式使用单独占行的 `$$`。支持 KaTeX 的 LaTeX 数学语法及 Markdown 常用文本格式；不支持完整 LaTeX 文档和自定义宏包。普通换行保留。公式不完整时显示源文/错误颜色，允许继续编辑和保存。

旧记录的可选 `storyFormat` / `reflectionFormat` 字段为空时，按普通文字显示，保留原文里的星号、美元符号和尖括号。用户主动点击格式工具或“启用格式”后，才将该字段设为 `markdown`。两处可以各自启用，保存及 JSON 导出保留语法原文和格式标记。未更改 schemaVersion，不迁移或覆盖浏览器中的现有记录。

## 日期与时间轴

旧原型将日期固定为 2026-10-05；现在按设备本地时区读取日历日期。跨午夜自动刷新，焦点/可见性恢复和定时检查会重新校准日期。首页英文日期、今天标记、日期输入默认值和校验、导出文件名使用同一个本地日历规则。

原时间轴把卡片左边作为日期坐标，但圆点位于卡片内侧约 20 像素，导致相隔一两天的节点看似越过今天。现在圆点与连接线共用真实日期坐标，普通、重要、里程碑、目标及聚合节点保持同一个中心。靠近今天的过去卡片朝左排布，今天标签留在独立空隙，不盖住卡片文字。聚合不跨越“过去 / 今天 / 未来”边界；概览中的今天位置也包含目标，同一天的重复节点可聚合。

目标试算从当天开始；资金余额仍按各笔记录的参考日保存，未把预测收益写成实际余额。资金说明展示每笔参考日，十年预测从当天开始；跨闰年的周年日期落在有效日历日。已有过去目标仍可原日编辑，新建或调整目标时校验当天日期。

- 模拟上海午夜自动更新，验证 UTC 与洛杉矶当地日期不同的场景，以及恢复页面后的日期刷新。离线重载可显示公式和本地公式字体。
- 以虚构“秋日散步”记录确认 10 月 4 日的圆点和卡片在 10 月 6 日之前，两种圆点的纵向中心一致。检查密集节点与不同跨度、分类筛选不修改记录。

- 用户 HTML 先清理再渲染数学公式，禁用受信任 LaTeX 外链命令，不加载文本中的远程图片。公式渲染器与字体全部随应用打包，授权附带。
