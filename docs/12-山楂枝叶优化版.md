# HawTend：山楂枝叶优化版

日期：2026-10-05。状态：历史优化版。用户指出 A2 像樱桃、五角星难以理解，要求重新设计，最终确认 **G 图案 + Lora**，已完成 [统一应用](14-G品牌统一与桌面更新.md)。下面保留 A2 的过程与当时的验证记录；旧预览链接现均显示 G，历史样式请查看保留的静态效果图。

## 用户已确定的选择

首轮 A/B/C/D 中，用户认为 A 的图案最好，仍希望进一步优化；B/C/D 的图标不能接受。英文 HawTend 字体明确选择 C 的 Lora。后续沿用山楂枝叶方向，本轮只提交一个优化版 A2。

## 本轮调整

- 重新连接枝条，让果梗接到果实上，去掉原来延伸到果实下方的线。
- 双果由近似并列改为一大一小、上下错落，果实轮廓作轻微的自然变化。
- 叶片与果实共同形成更紧凑的轮廓，保留鼠尾草绿与低饱和山楂红。
- 用简化的五角花萼代替原来的短折线，保留山楂特征。
- 字标使用用户已选的 Lora，字重 450，沿用 C 的字距、字号和文字颜色。

图标为原创 SVG：[A2 枝叶标记](../src/assets/brand-proposals/a2-branch.svg)。图标与字体分开绘制，沿用已有本地字体与许可，不新增远程字体请求。
