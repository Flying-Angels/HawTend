# Windows 退出与托盘图标

2026-10-06 · v0.0.10。

## 修正后的行为

- 托盘“退出 HawTend”关闭由此启动器管理的独立应用窗口，并在窗口关闭后停止本机页面服务、移除托盘图标。
- 点应用窗口右上角关闭按钮，也会停止本机服务；日历提醒无需让程序常驻。
- 重复双击 EXE、快捷方式或托盘“打开”，优先回到已有窗口，不反复创建新窗口。
- 独立应用窗口与普通 Edge 浏览器可能共享进程，因此不使用杀死 Edge 进程的方式退出。

默认仍使用现有 Edge 配置与 `http://127.0.0.1:4173/` 地址，以便继续读取同一份 IndexedDB。没有换用新的 WebView 配置，也没有迁移或清空用户数据。

## 窗口管理

启动链接使用一次性随机片段标记。页面短暂将其写入标题供原生程序识别；原生程序同时核对 Edge 进程、窗口类和不存在普通浏览器标签栏，再绑定窗口属性、进程 ID 与启动时间。完成握手后恢复正常标题和链接。片段不会改变网站来源。

关闭时，只向仍满足这些条件的窗口发送 `WM_CLOSE`，不广播关闭、不终止共享进程。取消浏览器关闭时保留服务。重复启动通过当前用户与端口对应的隐藏控制窗口唤回应用。本机 HTTP 服务新增的握手路径只返回状态，不接收关窗或写数据请求。

若未安装 Edge，会退回默认浏览器；若窗口验证未完成，不会擅自关闭普通浏览器。此时托盘菜单显示“停止本机服务”，页面需手动关闭。若 4173 已由源码预览或旧版程序提供，本次启动仅打开现有页面，不接管那个服务。

托盘使用独立的小尺寸山楂图案，保留单果与裂叶元素，加深颜色与轮廓。透明 ICO 包含 16、20、24、32、40、48 像素资源，按系统的小图标尺寸选择。网页、桌面快捷方式和已批准的 G 品牌标志继续使用各自资源。

## 验证与升级

Windows 本机测试使用独立测试端口 4191、独立 Edge 配置和虚构页面。实际验证托盘退出入口的关窗逻辑、右上角关窗后的服务停止、重复启动复用窗口，以及同一测试浏览器配置中的普通浏览器窗口仍然保留。未关闭用户当前 4173 的旧程序或窗口。其他 Windows 系统、DPI 环境和默认浏览器回退仍需实机反馈。

旧版尚在运行时，更新磁盘上的 EXE 不会替换已加载的程序。升级需先关闭旧手账窗口，再在旧托盘中退出一次，重新从桌面快捷方式打开。建议升级前在手账设置导出 JSON 留存。
