# 资金账户与手动市值

2026-10-06 · v0.0.11 本地原型

## 使用方式

打开 **资金安排 → 资金安排**。每月收支继续用于每月一次确认实际收入、支出；这里管理当前持有的资产。

1. 点击“管理账户”，添加支付宝、微信、银行或具体银行卡。名称和类型由自己设置，名称不能重复。
2. 点击已有资产，或“添加资金”，选择所在账户、资产类别和收益记录方式。
3. 基金默认使用“手动更新市值”。第一次填写当前市值和余额日期，作为后续变化的起点。
4. 之后点击“更新市值 / 盈亏”，填写最新市值，或填写上次记录以来的期间盈亏。可以每月一次，也可以按其他频率更新。

旧资金不被自动判断为基金，也不自动分配到某家银行。它们保留原金额、参考日期与原有年化设置，先显示在“暂未归到账户”；用户主动选择“基金 / 手动更新市值”后，才改变后续计算方式。切换时不会虚构早期收益。

## 账户、资产和可用性

| 设置 | 回答的问题 | 示例 |
| --- | --- | --- |
| 所在账户 | 钱放在哪里？ | 支付宝、微信、招商银行储蓄卡 |
| 资产类别 | 持有什么？ | 闲置余额、存款、基金、其他资产 |
| 收益记录方式 | 如何记录或推算变化？ | 固定年化假设、手动更新市值 |
| 可用性 | 是否锁定到期日？ | 可使用 / 可赎回，或锁定到期 |

一个账户可以有多项资产。例如支付宝中的闲置余额与基金分开记录，账户卡片自动相加；银行中的活期余额和定期存款同样可以分开记录。**不另外填写一份账户总额**，避免重复计算。

金额以分保存和展示。总资产是各资产最近一次记录的合计，日期可能不同；界面同时标出资产的余额或市值日期。选择账户只筛选明细、手动市值历史与该账户的固定年化试算，顶部仍是全部账户的汇总。

有资产的账户不能直接删除；先把资产移到其他账户或取消归属，再删除空账户。重命名不改变归属关系。账户修改和资产修改均可在保存提示中撤销。

基金的“可赎回”只表示当前设置不锁定到期日，计入可规划资金；页面明确说明这不代表立即到账，到账条件仍以实际产品为准。基金不再被标成普通银行活期。

## 市值与期间盈亏

“填写最新市值”适合直接查看平台上的持有金额；“填写期间盈亏”适合已知这段时间的盈利或亏损。盈利填正数，亏损填负数。这里的期间从上一条记录到本条记录，不强制等于一个自然月。

如果期间有追加、赎回或分红，展开“期间有买入、赎回或现金分红？”填写：

- **净投入 = 追加买入 − 赎回转出**，转出较多时为负数。
- **现金分红或派息**填实际转出的金额；红利再投已包含在市值中，不重复填写现金分红。

计算口径：

```text
期间盈亏 = 本次市值 − 上次市值 − 净投入 + 现金分红
本次市值 = 上次市值 + 净投入 + 期间盈亏 − 现金分红
```

虚构例子：原市值 8,000 元，追加 1,500 元，现金分红 100 元，现在市值 9,000 元。期间盈亏为 −400 元，而不是把市值增加的 1,000 元全当收益。

日期不能晚于设备当地今天，也不能早于最近一次记录。同一天保存会更正最近一条，不重复累加；更正仍以上一个记录日期的市值为起点。有市值历史后保留手动更新方式，避免切回固定年化导致历史与余额不一致。更早历史的直接编辑留待后续，目前可以更正最新一条或追加新日期。

历史区域展示初始起点、各次市值、期间盈亏及资金进出。累计盈亏只累计已有记录的期间，包含未实现的市值变化。实线连接真实填写的记录点，不宣称中间日期每天都已记录。

## 收支与规划的边界

市值浮动不会自动记作每月收入，也不会自动修改其他账户的闲置余额。买入基金时应减少来源账户的现金，赎回或现金分红实际到账后应更新接收账户余额。自己的账户之间转账不视为消费；逐笔交易和自动对账尚未实现。

手动市值资产不按旧年化继续复利，也不画成未来十年的固定收益曲线。目标规划使用其当前记录的可规划价值，并将未来收益假设视为 0%；这只是试算口径，不表示基金收益一定为零。固定年化资金继续保留已有计息规则和独立的虚线预测。

实际市值下降时仍允许保存。若当前可规划资产低于已预留给目标的金额，显示分配缺口，请用户检查目标；程序不会阻止记录真实亏损，也不会静默削减已有目标分配。

即使多个目标都已分配、总预留超过资产余额，也可以将其中一个目标的预留减少至零，再逐项重新安排，不会因其他目标的超额分配而无法调整。

## 实现与验证

账户和市值记录使用本机 IndexedDB，并包含在 JSON 导出中。新字段兼容没有账户和市值历史的旧手账；共享数据校验同步更新，尚未接入云同步，没有新增云数据库或第三方资金 API。

- 构建、资金计算、账户与市值检查、旧数据校验、月结算及当地日期检查通过。
- 独立浏览器验证旧金额保留、账户创建与重命名、资产换账户、账户筛选、现金与基金汇总、手动亏损、追加和分红、同日更正、撤销与刷新保留。
- 已用虚构数据验证样例不会改写个人手账，以及空账户删除后不能保存仍引用该账户的未提交资产。
- 桌面、820 像素平板和 390 像素手机视口检查金额显示和滚动；这是浏览器模拟视口，尚非 iPhone 实机验证。
- Windows 包继续在独立端口和独立浏览器配置中验证打开、重复启动、托盘退出与窗口关闭；不触碰用户正在使用的手账。
