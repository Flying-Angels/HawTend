## 开发与预览

Windows 日常体验现在可双击桌面的 **HawTend** 快捷方式，或直接打开 **`releases/windows/HawTend.exe`**，版本 0.0.6.0，约 2.95 MiB，页面内置、免安装，使用现有 Edge 打开独立窗口，不需要运行开发命令。Windows 和浏览器标签页图标均已去掉方形纸色底，保留透明的 G 山楂；桌面快捷方式引用同目录的 `HawTend-transparent.ico`。EXE 可以单独复制，个人手账仍在浏览器中，复制程序不会携带个人数据。完整说明、空白与样例规则见 [Windows 桌面版与空白手账](docs/10-Windows桌面版与空白手账.md)；本次分类功能、旧数据兼容与资源校验见 [自定义分类更新](docs/15-自定义分类与桌面更新.md)。

已经运行的旧 EXE 会继续提供旧页面。更新文件后，请先关闭手账窗口，再从右下角托盘退出 HawTend，然后双击桌面快捷方式；只关闭页面或刷新无法更新后台已加载的资源。此操作不清理同一浏览器来源的个人记录。

在这台电脑上，直接双击项目根目录的 **`启动HawTend.cmd`**。它会复用已运行的预览，或在后台启动本机预览，然后打开浏览器；不需要手动输入命令或部署服务器。默认地址为 [打开 HawTend](http://127.0.0.1:4173/)。电脑重启后再次双击即可。

源码 `index.html` 和 `dist/index.html` 不是独立的网页文件，不能通过双击加载完整 App。现在直接打开它们会显示预览指引。本机地址仅在此电脑使用，iPhone 需要后续免费 HTTPS 托管；不要在手机输入 `127.0.0.1`。启动入口不安装依赖、不改系统 PATH、不上传数据，日志放在忽略的 `output/preview/`；若缺少环境，会给出提示。当前进度及本次校验见 [当前进度与打开方式](docs/09-当前进度与打开方式.md)。

```powershell
npm ci
npm run build
npm run check:finance
npm run check:cloud
npm run preview
```

开发使用 `npm run dev`；离线检查使用构建后的 `npm run preview`。锁文件固定实际验证过的依赖。此电脑已有 Node 24.19.0；补充的 npm/npx 与 Playwright CLI 位于 `C:/Users/19620/.codex/tools/life-app-toolchain/node_modules/.bin/`，需要时临时加入当前终端 PATH，未修改系统 PATH。

Windows 打包由助手运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1`。`windows/` 和构建脚本纳入 Git，`releases/` 二进制产物排除。EXE 未签名，也尚无自动更新或其他电脑验证；当前已有的窗口启动和独立静态页面检查见上述说明。

`src/` 是原型代码，`public/` 包含清单和原创图标，`scripts/build-sw.mjs` 构建后生成离线页面缓存，`scripts/check-finance.ts` 检查资金边界。截图和浏览器检查辅助文件位于 `output/playwright/`，不进入 Git。原型的近似计算范围见设计文档，尚不能代替正式财务模型。
